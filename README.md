# Clade

An idle / incremental evolution game: grow a plant line in short side-view runs, release it into an island garden
that lives on while you're away, and climb a niche × tier list with better builds. Prototype; 2D, web, itch.io
first. v2, a rebuild since 2 Nov; v1 is in `_v1/`.

```
npm install
npm run dev     # the toys at /toys/ (the game comes back with M1)
npm run check   # typecheck and tests (prints only failures)
```
