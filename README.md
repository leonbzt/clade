# Clade

An idle / RPG evolution game: raise species on a young volcanic island, take a lineage on runs to young islands, and
bring the adapted line home to win a place in the island's ecosystem. Prototype; 2D, web, itch.io first.

```
npm install
npm run dev     # the game
npm run check   # typecheck and tests (prints only failures)
npm run sim     # headless sim, 5 seeds (SEEDS=1 MIN=30 for a quick look)
```
