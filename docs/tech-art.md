# Tech and art (proposals)

## Stack (recommended: web)

| Part         | Choice                                    | Why                                                                     |
| ------------ | ----------------------------------------- | ----------------------------------------------------------------------- |
| Language     | TypeScript                                | Safe refactoring; strongest AI support                                  |
| Build        | Vite                                      | Fast dev server with hot reload                                         |
| Menus        | Svelte (or Preact)                        | Menu-heavy idle UI is easiest in HTML/CSS                               |
| Landscape    | PixiJS for 2D, or Three.js for low-poly 3D | Decide after the art spikes                                             |
| Logic        | Plain TS modules, no DOM                  | Testable; the offline progress maths runs anywhere                      |
| Saves        | localStorage → later a cloud sync         | Simple first                                                            |

### Mobile: yes

- **Capacitor** wraps the web app into iOS and Android store apps.
- **A PWA** makes it installable from the browser.
- **Tauri or Electron** for Steam.

Plenty of idle games ship this way (Antimatter Dimensions and Cookie Clicker are web tech on Steam).

Caveats:
- Design touch-first and portrait from day one.
- Render only when the screen is visible; cap the frame rate (battery).
- Calculate offline progress on resume: the app is frozen while in the background.
- Local notifications through a Capacitor plugin.
- Test on a cheap Android phone early.

### Can it look good on web? Yes

PixiJS and Three.js handle lush 2D and 3D fine. **The limit is art direction, not tech.**

## Art with little manual work

**Approach:** stylised, shape-and-palette-driven art, generated by code. No painted illustration.

| What                     | How                                                                                                         | Who                         |
| ------------------------ | ----------------------------------------------------------------------------------------------------------- | --------------------------- |
| Island and terrain       | Procedural noise terrain, biome blending, a coastline, water shader                                          | Claude                      |
| Plants                   | **L-systems** (invented by a biologist to model plant growth) driven by genes: branching, leaf shape, colour, height | Claude                 |
| Animals                  | Parametric bodies (size, legs, colour, pattern from genes); simple procedural motion; shown small and in groups | Claude                  |
| "It's alive"             | Wind sway, drifting pollen, day/night tint, seasonal palettes, growth tweens, spreading animations           | Claude                      |
| Icons and UI             | SVG icons; CC0 packs (Kenney); game-icons.net (needs attribution)                                            | Claude, you pick            |
| **Art direction**        | Mood references, palette choice, "does this feel right?" on screenshots                                      | **You (essential)**         |
| Concept art (optional)   | AI image tools for mood boards. Claude can't make raster images                                               | You                         |

**Where Claude is strong:** procedural generation, shaders, particles, animation polish, layout, SVG.

**Where Claude is weak:** hand-drawn appeal, and judging feel without seeing it. So the loop is *screenshot → your
taste → adjust*.

**The pitfall:** procedural art can look like "programmer art". Fix it with:
- **a tight palette** (5–8 colours per biome)
- **consistent silhouettes**
- **one lighting mood**

### Art spikes (one session each, before committing)

1. **Flat 2D (PixiJS):** layered, soft gradients, top-down or slight perspective.
2. **Low-poly 3D diorama (Three.js):** a small rotatable island, flat-shaded, like Equilinox or Townscaper.

Judge both on a phone, with one L-system plant growing and spreading. Then pick.
